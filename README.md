# 로또 아틀리에 — 1등 확률을 먼저 확인하는 조합 구성

**[로또번호 생성기.html](로또번호%20생성기.html)을 열거나 새로고침하세요.** 인터넷·엑셀·추가 설치 없이 작동합니다.

1. 구매할 회차와 만들 게임 수를 고릅니다. 기본은 최신 공식 자료의 다음 회차·**5게임**이며, 값을 바꾸면 해당 묶음이 바로 생성됩니다.
2. 번호 목록 위에서 **선택 회차 전체의 1등 확률**을 확인합니다. 같은 회차의 보관 번호와 현재 묶음을 합친 고유 조합 수, 퍼센트, ‘몇 분의 1’을 함께 표시합니다.
3. 다른 번호를 원하면 **새 번호 만들기**를 누르고, 필요한 번호를 저장·복사하거나 CSV로 받습니다.
4. 1등 계산 기준·등위별 확률, 당첨번호 대조, 보관함은 아래의 접힌 항목을 펼쳐 확인합니다.

기본 5게임의 1등 확률은 **5 / 8,145,060 = 1,629,012분의 1 ≈ 0.00006139%**입니다. 한 번에 1~20게임을 만들며, 저장 후 같은 회차로 다시 생성하면 보관함의 기존 여섯 번호 조합과 겹치지 않는 새 묶음을 추가합니다. 화면의 큰 1등 확률은 선택 회차의 보관 번호와 현재 묶음을 모두 합쳐 중복 제거한 고유 조합 수로 계산합니다. 백분율은 소수점 이하 8자리로 반올림하고, 역수가 정수가 아닌 경우 ‘약’으로 표시합니다. 현재 묶음의 5등 이상 확률은 별도 보조 카드에 표시합니다.

빈도·시차·혼합 모형 선택과 고정·제외·합계·홀짝 조건을 화면에서 제거했습니다(이들은 당첨 확률을 바꾸지 못합니다). 적어도 한 게임이 당첨되는 확률을 넓히는 배치를 자동 적용합니다.

- **1~7게임:** 게임끼리 같은 번호를 사용하지 않습니다.
- **8~20게임:** 45개 번호를 고르게 쓰고, 두 게임의 공통 번호를 최대 1개로 제한합니다.
- 모든 번호를 공정한 난수로 일대일 치환합니다. 배치가 같으면 번호를 새로 섞어도 확률은 같습니다.

| 같은 게임 수 | 무작위 묶음 평균: 5등 이상 | 현재 배치: 5등 이상 |
|---:|---:|---:|
| 5 | 11.3624% | 11.8679% |
| 10 | 21.4337% | 23.0209% |
| 15 | 30.3607% | 33.4643% |
| 20 | 38.2734% | 42.6318% |

기본 5게임의 확률은 앞 버전의 완전 분산 방식과 같습니다. 이번 알고리즘 개선은 주로 8~20게임 구성에 해당합니다. 비교는 항상 **같은 게임 수**를 기준으로 합니다.

현재 배치는 **4등 이상 한 장이라도 당첨될 확률이 같은 게임 수의 수학적 상한**에 도달합니다. 5등 이상 확률의 전역 최적성은 증명하지 않았습니다. 1등 확률은 서로 다른 m게임이면 어느 구성이나 m/8,145,060이며, 기대 당첨 장수나 수익을 늘린다는 뜻은 아닙니다. 확률은 공정·독립 추첨을 가정합니다. [동행복권 공식 규칙](https://m.dhlottery.co.kr/lt645/intro)

화면의 큰 1등 확률은 **선택한 같은 한 회차에 사용할 현재 묶음과 보관 번호 전체**의 값입니다. 새 번호는 같은 회차의 보관 조합을 강제 제외하며, 기존 자료 중 회차가 기록되지 않은 묶음은 합산하지 않습니다. 보관하지 않은 종이 복권이나 다른 기기의 번호는 알 수 없으므로 직접 합산되지 않습니다.

## 인기 번호대 피하기 — 확률은 같게, 당첨 시 몫은 크게

1등 확률은 어떤 번호를 골라도 같습니다. 달라질 수 있는 것은 **당첨됐을 때 몇 명과 나누는가**뿐입니다. 판매 조합 자료는 공개되지 않지만 회차별 1등 당첨자 수는 공개되므로, 공식 522회(720~1241회)로 직접 추정했습니다.

- 모형: `log E[1등 당첨자 수] = log(1등 총당첨금) + a + β × (번호 합계 − 138) / 100` (포아송 회귀, 총당첨금은 판매량의 대리 변수).
- 결과: **β = −0.347 (표준오차 0.062, z = −5.6)**. 합계가 100 낮으면 1등 당첨자가 약 41% 많습니다. 전반 261회 −0.347, 후반 261회 −0.345로 같고, 당첨자 30명 초과 회차를 빼도 −0.314입니다.
- 표본 외 검증: 시간순 10블록 교차검증 이탈도가 상수 모형 1021.7 → 합계 모형 960.8로 개선됩니다. 번호 45개를 따로 추정하는 모형(능형 회귀)은 상수 모형보다도 나빠 채택하지 않았습니다. 7 포함 여부, 연속 번호 개수 등은 이 표본에서 유의하지 않았습니다.
- 적용: 배치의 **번호 치환 후보 300개**(모두 모든 등위의 당첨 확률이 같음) 중 공동 당첨자 추정이 가장 적은 묶음을 고릅니다. 합계는 관측 5~95% 구간(91~191)으로 잘라 외삽에 점수를 주지 않습니다. 표본이 적어 추정할 수 없는 모양(연속 3개 이상, 모두 31 이하, 12 이하 4개 이상, 용지 같은 줄·칸 4개 이상, 같은 끝수 4개 이상, 같은 간격 배열, 과거 1등 번호)은 해외 연구에 근거해 단순히 피하며, 남으면 두 번호를 전체에서 맞바꾸는 방식으로 고칩니다. 맞바꿈도 번호 치환이므로 확률은 그대로입니다.
- 효과(예상 1등 수령액, 평균적인 조합 대비): 1게임 약 +20%, 5게임 약 +8%, 10게임 약 +3%, 20게임 약 +1~2%. 8게임 이상은 45개 번호를 고르게 쓰므로 여지가 작습니다.

한계: 수동 구매자의 선호를 합계 하나로 요약한 근사이며, 자동 구매 비중이 커서 효과가 제한적입니다. 1등 총당첨금은 4·5등 지급액의 영향을 받아 판매량과 정확히 비례하지는 않습니다. **당첨 확률, 기대 당첨 횟수는 전혀 늘지 않고 복권의 기대 수익은 여전히 음수입니다.** 재계산은 `node scripts/analyze-split-risk.cjs`(결과 `data/split-risk.json`), 검사는 `node --test tests/split.test.cjs`입니다. 화면의 ‘인기 번호대 피하기’를 끄면 이전과 같은 균등 치환을 사용합니다.

보관함은 기존 버전의 로컬 저장 키를 유지했습니다. 브라우저·파일 위치를 바꾸거나 브라우저 데이터를 삭제하면 기록 접근이 달라질 수 있습니다. 중요한 번호는 CSV로 보관해 주세요. 당첨번호 대조는 공식 720~1241회(2026-09-12까지)의 저장 자료를 사용하며 자동 갱신되지 않습니다. 이후 회차는 직접 입력할 수 있습니다. 과거 대조는 미래 예측 성적이 아닙니다.

자세한 비교, 1~20게임 수치, 고정번호·휠링 검토, 확률 상한 증명, 정확식, 탐색 범위와 한계는 **[ANALYSIS.md](ANALYSIS.md)**에 있습니다.

과거 1등 당첨 조합을 참고한 추가 연구는 **[JACKPOT_ANALYSIS.md](JACKPOT_ANALYSIS.md)**에 있습니다. 공식 522회를 10가지 방식으로 분류하고 전체 8,145,060개 조합의 유형별 개수를 정확히 세었습니다. 과거 빈도로 만든 11개 대안과 균등 기준을 순차 비교했지만 미래 1등 확률 우위는 확인하지 못했습니다. [전체 유형 통계·1242회 실험 추정 CSV](data/jackpot-exports/type-probabilities.csv)와 [522회 번호·유형 CSV](data/jackpot-exports/draw-types.csv)를 함께 제공합니다. 실험 추정은 검증된 미래 확률이 아니며 생성 방식에 예측 가중치로 적용하지 않았습니다.
