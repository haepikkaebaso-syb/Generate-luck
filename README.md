# 로또 아틀리에 — 1등 확률을 먼저 확인하는 조합 구성

**[로또번호 생성기.html](로또번호%20생성기.html)을 열거나 새로고침하세요.** 인터넷·엑셀·추가 설치 없이 작동합니다.

1. 만들 게임 수를 고릅니다. 기본은 **5게임**이며, 수를 바꾸면 해당 묶음이 바로 생성됩니다.
2. 번호 목록 위에서 **현재 묶음의 1등 확률**을 확인합니다. 퍼센트, ‘몇 분의 1’, 정확한 경우의 수를 함께 표시합니다.
3. 다른 번호를 원하면 **새 번호 만들기**를 누르고, 필요한 번호를 저장·복사하거나 CSV로 받습니다.
4. 1등 계산 기준·등위별 확률, 당첨번호 대조, 보관함은 아래의 접힌 항목을 펼쳐 확인합니다.

기본 5게임의 1등 확률은 **5 / 8,145,060 = 1,629,012분의 1 ≈ 0.00006139%**입니다. 1~20게임 선택에 맞춰 실제 생성된 여섯 번호 조합을 중복 제거한 개수로 계산합니다. 같은 회차에서 현재 묶음 중 한 게임이라도 1등에 당첨될 확률이며, 보관함의 다른 묶음이나 과거 당첨률은 합산하지 않습니다. 백분율은 소수점 이하 8자리로 반올림하고, 역수가 정수가 아닌 경우 ‘약’으로 표시합니다. 5등 이상 확률은 별도 보조 카드에 표시합니다.

빈도·시차·혼합 모형 선택과 고정·제외·합계·홀짝 조건을 화면에서 제거했습니다. 적어도 한 게임이 당첨되는 확률을 넓히는 배치를 자동 적용합니다.

- **1~7게임:** 게임끼리 같은 번호를 사용하지 않습니다.
- **8~20게임:** 45개 번호를 고르게 쓰고, 두 게임의 공통 번호를 최대 1개로 제한합니다.
- 모든 번호를 공정한 난수로 일대일 치환합니다. 배치가 같으면 번호를 새로 섞어도 확률은 같습니다.

| 같은 게임 수 | 무작위 묶음 평균: 5등 이상 | 현재 배치: 5등 이상 |
|---:|---:|---:|
| 5 | 11.3624% | 11.8679% |
| 10 | 21.4337% | 23.0209% |
| 15 | 30.3607% | 33.4643% |
| 20 | 38.2734% | 42.6318% |

기본 5게임의 확률은 앞 버전의 완전 분산 방식과 같습니다. 이번 알고리즘 개선은 주로 8~20게임 구성에 해당합니다. 비교는 항상 **같은 게임 수**를 기준으로 합니다.

현재 배치는 **4등 이상 한 장이라도 당첨될 확률이 같은 게임 수의 수학적 상한**에 도달합니다. 5등 이상 확률의 전역 최적성은 증명하지 않았습니다. 1등 확률은 서로 다른 m게임이면 어느 구성이나 m/8,145,060이며, 기대 당첨 장수나 수익을 늘린다는 뜻은 아닙니다. 확률은 공정·독립 추첨을 가정합니다. [동행복권 공식 규칙](https://m.dhlottery.co.kr/lt645/intro)

화면의 확률은 **현재 묶음을 같은 한 회차에 사용할 때**의 값입니다. 여러 번 생성한 묶음을 합치면 묶음 사이에 겹침이 생길 수 있으므로 표시 확률을 더하면 안 됩니다. 이전 보관함의 번호는 강제 제외하지 않습니다.

보관함은 기존 버전의 로컬 저장 키를 유지했습니다. 브라우저·파일 위치를 바꾸거나 브라우저 데이터를 삭제하면 기록 접근이 달라질 수 있습니다. 중요한 번호는 CSV로 보관해 주세요. 당첨번호 대조는 공식 720~1241회(2026-09-12까지)의 저장 자료를 사용하며 자동 갱신되지 않습니다. 이후 회차는 직접 입력할 수 있습니다. 과거 대조는 미래 예측 성적이 아닙니다.

자세한 비교, 1~20게임 수치, 고정번호·휠링 검토, 확률 상한 증명, 정확식, 탐색 범위와 한계는 **[ANALYSIS.md](ANALYSIS.md)**에 있습니다.

과거 1등 당첨 조합을 참고한 추가 연구는 **[JACKPOT_ANALYSIS.md](JACKPOT_ANALYSIS.md)**에 있습니다. 공식 522회를 10가지 방식으로 분류하고 전체 8,145,060개 조합의 유형별 개수를 정확히 세었습니다. 과거 빈도로 만든 11개 대안과 균등 기준을 순차 비교했지만 미래 1등 확률 우위는 확인하지 못했습니다. [전체 유형 통계·1242회 실험 추정 CSV](data/jackpot-exports/type-probabilities.csv)와 [522회 번호·유형 CSV](data/jackpot-exports/draw-types.csv)를 함께 제공합니다. 실험 추정은 검증된 미래 확률이 아니며 생성 방식에 예측 가중치로 적용하지 않았습니다.

개발·검증 자료:

- `dist/index.html`, `dist/styles.css`, `dist/app.js`: 간편 화면.
- `dist/portfolio.js`: 배치별 정확한 당첨 영역과 번호 치환.
- `data/portfolio-templates.json`: 확정된 1~20게임 배치.
- `data/portfolio-research/`: 탐색 코드, 후보·비교 시드, 별도 전수 평가와 검산 결과.
- `data/portfolio-provenance.json`: 연구 산출물 해시.
- `data/jackpot-research/`, `data/jackpot-provenance.json`: 1등 유형 실험·독립 검산·원본 해시.
- `node --test tests/jackpot-*.test.cjs`: 1등 유형 계산·확률 정규화·순차 검증·원본 일치 검사.
- `tests/jackpot-ui.test.cjs`: 실제 앱 코드의 1~20게임 확률 표시, 중복 제거, 저장·대조 시 확률 유지, 생성 실패 처리를 브라우저 없는 실행 환경에서 검사합니다.
- `archive/v3/ANALYSIS.md`: 이전 10년 빈도·회차 간 예측 실험 보고서. 이전 연구 자료는 `data/`에 보존했습니다.
- `npm.cmd test`: 계산·입력·치환·기존 기록 호환에 사용되는 핵심 모듈과 정적 구성을 검사합니다.
- `npm.cmd run build`: 배치와 검증 자료를 확인해 단일 HTML 및 분석 문서를 만듭니다.

브라우저 화면·클릭 동작은 자동 검사하지 않았습니다. JavaScript 구문, 정적 페이지 구성, 확률 계산과 자료 일치를 검사했습니다. 연구 재현 코드는 당시 작업공간 경로를 기록하고 있으므로 다른 위치에서 재실행하려면 입력 경로를 확인하세요. 새로운 탐색 출력은 현재 배치로 자동 반영하지 않으며, 검산 후 템플릿과 해시 목록을 함께 갱신해야 합니다.
